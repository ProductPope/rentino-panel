# Rentino panel

Rentino admin panel. UI comes only from the EQ-librium design system (`@eq` shadcn registry);
there is no backend yet — data and session are mocked behind typed interfaces.

```bash
pnpm install
pnpm dev          # http://localhost:3000 → Settings → Discount codes
pnpm build && pnpm test:e2e
```
